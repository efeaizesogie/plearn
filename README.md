# plearn 🚀
### Playful Coding School for Kids

**plearn** is a playful, interactive landing page for an after-school coding school designed for kids ages 7 to 14. Built with React, Vite, Tailwind CSS, Lucide icons, and Framer Motion.

---

## ✨ Features

- **🎮 Playful Pop Sorbet Design System**: Chunky card frames, hard drop shadows, curated color palette (`#FFF8EE`, `#FFE9D2`, `#1D1A2F`, `#FF5A36`, `#7B61FF`), and friendly typography (*Fredoka* & *Nunito*).
- **🕹️ Draggable Hero Stickers**: Interactive stickers including a physics-based draggable code laptop, retro game controller, and code badges.
- **🏝️ Interactive 3D Diorama Sandbox**: Visual learning diorama with interactive pulsating hotspots revealing learning tools, kid-friendly game engines, and mentor guidance.
- **🔄 3-Step Milestone Journey**: Clear 3-step loop cards showcasing visual block stories, arcade games, and modern Python/Web apps.
- **💬 Community & Social Proof**: Live peer project gallery, parent testimonials, and satisfaction metrics.
- **💳 Transparent Pricing & FAQ**: Single clear after-school club plan with accordion FAQ and 14-day guarantee.
- **🚀 Guided "Get Started" Modal**: 3-step onboarding questionnaire tailored for parents and kids.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion (Framer Motion)](https://motion.dev/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or newer) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/efeaizesogie/plearn.git
   cd plearn
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
